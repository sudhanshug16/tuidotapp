# Changelog

## 0.1.5

- Create dedicated, independently named macOS apps for local and SSH-hosted TUIs.
- Render through Ghostty with mouse reporting, selection, clipboard, scrollback, and native scrollbars.
- Resolve commands through the user's login shell without copying TUI executables.
- Add per-profile icons, searchable light and dark themes, and Ghostty config passthrough.
- Add optional Command-to-Control key mapping while preserving Copy, Paste, and Quit.
- Remember created app locations so their embedded terminal host can be updated in one click.
- Prevent failed app or icon replacements from destroying the previous working copy.
- Preserve unreadable profile libraries and provide an explicit backup-and-reset recovery path.
- Add visible input validation, protected deletion, profile duplication, and a GitHub release check.
